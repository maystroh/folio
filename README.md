# Folio

A focused, local-first PDF reader for Windows with annotations, signatures, workspaces, export, and printing.

[Download latest release](https://github.com/maystroh/folio/releases/latest) · [Full guide](docs/GUIDE.md) · [Build and test](docs/GUIDE.md#run-from-source)

Download and extract the Windows ZIP, then run **Install Folio.cmd**. All processing stays on your computer.
